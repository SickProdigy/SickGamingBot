# Command guides

- [Member commands](members.md) cover everyday utilities, games, media, profiles, and self-service actions.
- [Staff commands](staff.md) cover moderation and delegated feature management.
- [Server-owner commands](server-owners.md) cover guild-wide policy and configuration.

These are practical starting points, not permission grants or raw exports of every
subcommand. Replace `[p]` with the server's prefix and use `[p]help <command>` for
current syntax, aliases, and access checks.

The old generated lists remain available as [legacy snapshots](../legacy-command-lists.md),
but they are not the current permission model.

## Baseline

The feature baseline was reviewed against the testing bot's Red cog data on
2026-10-10. It includes Red core features and Sick-Cogs features such as Ark, Clash of
Clans, DayZ, Game Roles, Giveaways, Garry's Mod, Icarus, Meme, Movie Releases,
Navidrome, Rocket League, Role Tools, RuneScape, Welcome, and Wolfram.

A cog data directory confirms that the bot has configuration for that feature; it does
not prove that the cog is loaded or enabled in every server. Live help remains
authoritative.

Age-restricted commands are intentionally omitted from the general command guides.
