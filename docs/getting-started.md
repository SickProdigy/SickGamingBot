# Getting started

## In a server that already has SickGamingBot

SickGamingBot commands use the `-` prefix. Start with:

    -help
    -help <command>

Discord may hide commands you cannot use, and individual features may be disabled.

Continue with the [member guide](members/index.md), [staff guide](staff/index.md), or [server-owner guide](server-owners/index.md).

## Adding the bot

Only use an invite published by SickGaming or an approved Discord application listing. Review requested permissions before authorizing it. You must be allowed to manage the destination server.

You can get the official invitation in either of these ways:

- Send `-invite` in a direct message to SickGamingBot.
- Open the published [SickGamingBot invite](https://discord.com/oauth2/authorize?client_id=691452746632658954&scope=bot&permissions=0).

Both methods use the same Discord authorization link.

After adding the bot:

1. Confirm it can view and send messages in the intended bot channel.
2. Run `-help` to verify the bot and view available commands.
3. Decide which roles should manage moderation and optional features.
4. Configure integrations individually; never paste credentials into public channels.

Server owners should continue with [Initial setup](server-owners/initial-setup.md). For problems, see [Troubleshooting](troubleshooting.md).
