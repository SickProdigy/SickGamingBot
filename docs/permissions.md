# Permissions

Access is determined at runtime, not by documentation alone. The effective result can include Discord guild and channel permissions, role hierarchy, Red command checks, server-specific Red Permissions rules, disabled commands or cogs, feature-manager roles, and required integrations.

| Audience | Intended scope |
| --- | --- |
| Member | Everyday commands and actions affecting the member's own account |
| Moderator | Routine moderation and incident response |
| Administrator | Guild-wide configuration and sensitive management |
| Server Owner | Guild ownership decisions and initial integration approval |
| SickGaming Maintainer | Bot process, code, global credentials, infrastructure, and global policy |

Discord Administrator, Discord server ownership, and Red bot ownership are different things. A server owner does not automatically receive bot-host commands.

Audience labels are not a security control. Use [p]help and direct command help to see the current result for your account.
