# Pokémon

> A global catching and battle game with collections, parties, research, gyms, trading, and trainer progress.

## At a glance

- **Category:** Games and gaming communities
- **Intended audience:** Members play; administrators configure server behavior; maintainers manage global settings.
- **Loaded package:** `pokemon`
- **Documented commands:** 73 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-pokemon` | Member | Play the global Pokémon catching and battle game. |
| `-pokemonownerset` | Bot maintainer | Configure bot-wide Pokémon policy and owner overrides. |
| `-pokemonset` | Administrator or required permission | Configure Pokémon without cluttering player commands. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help pokemon
-help pokemon <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
