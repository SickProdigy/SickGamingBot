# DayZ

> Official DayZ news with browsing, filtering, and automatic announcements.

## At a glance

- **Category:** Games and gaming communities
- **Intended audience:** Members browse updates; administrators configure announcements.
- **Loaded package:** `dayz`
- **Documented commands:** 15 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-dayz` | Member | Browse official DayZ Steam announcements. |
| `-dayzset` | Administrator or required permission | Configure official DayZ announcements. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help dayz
-help dayz <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
