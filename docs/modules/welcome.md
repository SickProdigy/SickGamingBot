# Welcome

> Welcome and goodbye messages, channels, embeds, and onboarding behavior.

## At a glance

- **Category:** Community and server management
- **Intended audience:** Administrators configure it; members receive its automated messages.
- **Loaded package:** `welcome`
- **Documented commands:** 46 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-welcomeset` | Administrator or required permission | Sets welcome module settings |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help welcomeset
-help welcomeset <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
