# Permissions

> Server-specific rules that allow or deny commands and cogs for users, roles, or channels.

## At a glance

- **Category:** Moderation and safety
- **Intended audience:** Server owners and administrators managing access policy.
- **Loaded package:** `permissions`
- **Documented commands:** 19 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-permissions` | Member | Command permission management tools. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help permissions
-help permissions <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
