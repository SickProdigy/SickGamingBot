# RSS Publisher

> Feed subscriptions, scheduled checks, filtering, formatting, and publication.

## At a glance

- **Category:** Music, media, and feeds
- **Intended audience:** Members may inspect feeds; administrators configure publishers.
- **Loaded package:** `rsspublisher`
- **Documented commands:** 44 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-rsspublisher` | Moderator or required permission | Manage this server's RSS and Atom feeds. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help rsspublisher
-help rsspublisher <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
