# Trivia

> Category-based trivia sessions with scoreboards and configurable session behavior.

## At a glance

- **Category:** Games and gaming communities
- **Intended audience:** Members play trivia; administrators configure it.
- **Loaded package:** `trivia`
- **Documented commands:** 21 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-trivia` | Member | Start trivia session on the specified category. |
| `-triviaset` | Moderator or required permission | Manage Trivia settings. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help trivia
-help trivia <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
