# Meme

> Meme discovery, creation, templates, and image transformations.

## At a glance

- **Category:** Music, media, and feeds
- **Intended audience:** Members use meme tools; administrators configure providers and limits.
- **Loaded package:** `meme`
- **Documented commands:** 20 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-meme` | Member | Post or search for online memes and GIFs. |
| `-memeify` | Member | Create a meme: `memeify <template> <top> \| <bottom>`. |
| `-memeset` | Administrator or required permission | Configure automatic meme feeds. |
| `-memeversion` | Member | Show the installed Meme cog version. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help meme
-help meme <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
