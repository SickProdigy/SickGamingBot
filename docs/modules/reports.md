# Reports

> Member-submitted reports delivered to configured staff channels.

## At a glance

- **Category:** Moderation and safety
- **Intended audience:** Members submit reports; administrators configure reporting.
- **Loaded package:** `reports`
- **Documented commands:** 5 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-report` | Member | Send a report. |
| `-reportset` | Administrator or required permission | Manage Reports. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help report
-help report <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
