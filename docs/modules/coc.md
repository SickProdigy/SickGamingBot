# Clash of Clans

> Clash of Clans player, clan, war, capital, and league information.

## At a glance

- **Category:** Games and gaming communities
- **Intended audience:** Members use lookups; administrators configure server defaults.
- **Loaded package:** `coc`
- **Documented commands:** 22 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-coc` | Member | Show Clash of Clans clan information and war results. |
| `-cocset` | Member | Configure this server's Clash of Clans integration. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help coc
-help coc <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
