# Aliases

> Alternative names that make frequently used commands easier to remember.

## At a glance

- **Category:** Community and server management
- **Intended audience:** Members can inspect aliases; moderators manage server aliases; maintainers manage global aliases.
- **Loaded package:** `alias`
- **Documented commands:** 12 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-alias` | Member | Manage command aliases. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help alias
-help alias <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
