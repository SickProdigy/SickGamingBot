# Role Tools

> Self-service roles and advanced role assignment behavior.

## At a glance

- **Category:** Community and server management
- **Intended audience:** Members choose allowed roles; administrators configure role tools.
- **Loaded package:** `roletools`
- **Documented commands:** 113 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-roletools` | Member | Member role help and server role-management commands. |
| `-selfroles` | Member | List available self-roles. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help roletools
-help roletools <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
