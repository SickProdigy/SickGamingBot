# Wolfram

> Wolfram queries, image results, and step-by-step math solutions.

## At a glance

- **Category:** Economy, information, and utilities
- **Intended audience:** Members; maintainers configure the API integration.
- **Loaded package:** `wolfram`
- **Documented commands:** 4 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-wolfram` | Member | Ask Wolfram\|Alpha a factual, mathematical, or scientific question. |
| `-wolframexample` | Member | Show a curated Wolfram example. |
| `-wolframimage` | Member | Ask Wolfram\|Alpha a question and return an image. |
| `-wolframsolve` | Member | Ask Wolfram\|Alpha a math question and return step-by-step answers. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help wolfram
-help wolfram <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
