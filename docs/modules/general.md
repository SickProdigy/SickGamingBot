# General

> Everyday utilities such as choices, dice, server information, stopwatch, and urban dictionary.

## At a glance

- **Category:** Economy, information, and utilities
- **Intended audience:** Members.
- **Loaded package:** `general`
- **Documented commands:** 10 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-8` | Member | Ask 8 ball a question. |
| `-choose` | Member | Choose between multiple options. |
| `-flip` | Member | Flip a coin... or a user. |
| `-hug` | Member | Because everyone likes hugs! |
| `-lmgtfy` | Member | Create a lmgtfy link. |
| `-roll` | Member | Roll a random number. |
| `-rps` | Member | Play Rock Paper Scissors. |
| `-serverinfo` | Member | Show server information. |
| `-stopwatch` | Member | Start or stop the stopwatch. |
| `-urban` | Member | Search the Urban Dictionary. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help 8
-help 8 <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
