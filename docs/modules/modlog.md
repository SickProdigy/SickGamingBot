# Moderation Log

> Moderation cases, case histories, and case reasons.

## At a glance

- **Category:** Moderation and safety
- **Intended audience:** Moderators and administrators.
- **Loaded package:** `modlog`
- **Documented commands:** 4 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-case` | Member | Show the specified case. |
| `-casesfor` | Member | Display cases for the specified member. |
| `-listcases` | Member | List cases for the specified member. |
| `-reason` | Member | Specify a reason for a modlog case. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help case
-help case <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
