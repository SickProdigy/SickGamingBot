# Movie Releases

> Movie discovery plus configurable release announcement channels and schedules.

## At a glance

- **Category:** Music, media, and feeds
- **Intended audience:** Members browse movies; administrators configure announcements.
- **Loaded package:** `movies`
- **Documented commands:** 15 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-movies` | Member | Search for a movie by title, or show movie suggestions. |
| `-movieset` | Moderator or required permission | Configure new movie release announcements. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help movies
-help movies <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
