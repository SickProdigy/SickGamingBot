# Filter

> Filtered words, member-specific filters, and filter behavior.

## At a glance

- **Category:** Moderation and safety
- **Intended audience:** Moderators manage entries; server owners configure behavior.
- **Loaded package:** `filter`
- **Documented commands:** 14 commands and subcommands

## Main command families

| Command | Default access | Purpose |
| --- | --- | --- |
| `-filter` | Moderator or required permission | Base command to add or remove words from the server filter. |
| `-filterset` | Administrator or required permission | Base command to manage filter settings. |

## Using this module

Run help for a command family, then add subcommands to request more specific details:

```text
-help filter
-help filter <subcommand>
```

The bot only shows commands available to your account. Server-specific permission
rules, disabled commands, required integrations, and channel restrictions can change
what you can use.
