# Member guide

Member features are ordinary commands and self-service actions that do not change server-wide policy.

## Common activities

- Ask for help with [p]help or [p]help <command>.
- Use utilities, search, profiles, games, reminders, economy, and media features enabled by the server.
- Join approved self-service roles through the server's role menus.
- View public server information and feature status.
- Connect your own account when a feature provides a private linking flow.

## Account connections

Only connect accounts through the bot's documented private prompt or an approved SickGaming website. Never post API tokens, passwords, recovery codes, or one-time authorization links in a channel.

Connecting an account does not bypass the external service's permissions. Members do not configure server-wide credentials, moderation policy, announcement destinations, or bot hosting.

Browse [Features](../features/index.md), [Permissions](../permissions.md), and [Troubleshooting](../troubleshooting.md) for more detail.
