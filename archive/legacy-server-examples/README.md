# Legacy SickGaming server examples

These files preserve historical SickGaming Discord setup notes and examples. They are
backups, not current setup instructions or a complete description of the bot.

- `Giveaways.md` records old giveaway commands and server-specific posting examples.
- `Reaction-Roles.md` occupies the historical reaction-role guide location; current
  Role Tools can manage complete channel role lists differently.
- `Streams.md` preserves the retired root-level stream guide.
- `Welcome-Message.md` preserves the retired root-level welcome guide.

For current behavior, use the documentation under `docs/modules/`, the server-owner
setup guide, and live `-help <command>` output. Historical channel IDs, examples,
command shapes, and relative links in this archive may be obsolete.
